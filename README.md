#  Community Waste Reporting and Collection System 
 
 A proposed digital system that helps residents in Sierra Leone report waste accumulation and track waste collection progress. 
 
##  Aim 
To design a logical system for submitting waste reports and updating their status. 
 
 Key Features 
-Waste reporting and input validation 
-Unique report reference numbers 
-Status tracking: Pending, In Progress, and Resolved 
 
 Programming Concepts 
-Algorithms and pseudocode 
-Flowcharts 
-Variables and data types 
-Decision structures and Boolean logic 
-Repetition structures 
-Functions and modular design 
 
##  Project Status 
This is an academic logical design. A fully functioning application has not yet been developed. 
 
 Course: PROG101 – Principles of Programming Logic and Design   
 Institution: Limkokwing University of Creative Technology, Sierra Le 

 ## Problem Identification 
 Some communities in Sierra Leone experience uncollected waste, blocked drains, and poor waste disposal

 ## People Affected
 # Residents and household
 Experience dirty surroundings and potential health risks
 
 # Market Traders and business owners
 May face unhygienic working environments.
 
 # Children and students
 May be exposed to unhealthy surroundings
 
 # The community
 Need organized reports to monitor and respond to complaints

 ## Proposed Solution
 A system that allows residents to report uncollected waste, receive reference numbers, and track report status.
